### Task 2: 修复菜单 — 打通 `recentProjects` 和 `currentSession` 数据流

**Covers:** 让 macOS 菜单「Open Recent」和「Open in Terminal」实际可用

**现状:**
- `menu.ts` 定义了 `Deps` 接口包含 `recentProjects?`、`onOpenRecent?`、`currentSession?`，并正确使用它们渲染子菜单
- `index.ts:240-254` 的 `wireMenu()` 调用 `createMenu()` 时只传了 4 个参数，遗漏了上述 3 个字段
- `workspace-recent.ts` 已有 `getRecentProjects()` 可以从 store 读取历史项目
- renderer 端已有 `window.__OPENCODE__.recentProjects` 数据（通过 `env.d.ts` 声明）

**注意:** macOS 菜单是应用启动时创建的静态结构，要刷新 recent projects 需要重建菜单或订阅更新。简单方案：在 `wireMenu()` 时读取一次 `getRecentProjects()`；renderer 在切 workspace 时主动推送 `setRecentProjects` 已通过 IPC 写入 store。菜单在 app 重新 focus 时（点击菜单栏时 macOS 会调用 window 的 focus）或当 mainWindow.show 时刷新。

**实现思路：** 在 `wireMenu()` 中读取 `getRecentProjects()` 传入 `createMenu` + 通过 renderer 的 `onMenuCommand("/workspace/changed")` 或 app focus 事件来重建菜单。

最简洁的方案：在 `app.on("activate")` 和 `mainWindow.on("focus")` 时重新调用 `wireMenu()`（会覆盖 Menu.setApplicationMenu）。

- [ ] **Step 1: 修改 `packages/desktop/src/main/index.ts` — 为 `wireMenu` 提供 recentProjects**

```typescript
// 在文件顶部已导入: import { getRecentProjects, ... } from "./workspace-recent"

// 修改 wireMenu() 函数（约 line 240-254）：
function wireMenu() {
  if (!mainWindow) return
  createMenu({
    trigger: (id) => mainWindow && sendMenuCommand(mainWindow, id),
    checkForUpdates: () => {
      void checkForUpdates(true)
    },
    reload: () => mainWindow?.reload(),
    relaunch: () => {
      killSidecar()
      app.relaunch()
      app.exit(0)
    },
    // 新增：从 store 读取 recent projects
    recentProjects: getRecentProjects(),
    onOpenRecent: (dir: string) => {
      mainWindow?.webContents.send("menu-command", "project.open")
    },
    currentSession: undefined, // Task 2b 实现
  })
}
```

- [ ] **Step 2: 让菜单在 app 被激活时刷新**

在 `setupApp()` 或 `initialize()` 完成后，监听 app activate 事件重建菜单。

```typescript
// 在 createMainWindow() 之后 / wireMenu() 调用之后添加：
app.on("activate", () => {
  if (mainWindow) wireMenu()
})
```

- [ ] **Step 3: （可选，取决于 Session 上下文）为 `currentSession` 提供数据**

最简单：在 IPC handler 中注册 `"set-current-session"`，renderer 切换 session 时调用。

**简化方案：** 将 `currentSession` 始终设为 `undefined`，"Open in Terminal" 菜单保持只执行 `mimo`。这样可以先发布 T2 的大部分功能（recent projects 可用），currentSession 留到后续版本。
